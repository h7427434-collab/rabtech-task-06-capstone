# RabTech Task 06 — Production Capstone Project

A responsive full-stack style capstone application demonstrating authentication simulation, interactive product management, CRUD operations, search, and persistent browser storage.

## Features

- Simulated user authentication
- Login and logout functionality
- Interactive product catalog
- Add products dynamically
- Edit products
- Delete products
- Search products
- Persistent state using localStorage
- Responsive mobile-first interface
- Accessible HTML structure

## Technologies

- HTML5
- CSS3
- JavaScript
- DOM API
- Browser localStorage

## Project Structure

- `index.html` — Application structure
- `style.css` — Responsive styling
- `app.js` — Authentication, DOM logic, CRUD operations and persistence

## Deployment

The project is designed for deployment using GitHub Pages.
